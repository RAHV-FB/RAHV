# Your Home Barcelona — image asset pack

This pack is organized for a first website design pass.

## Folder structure

- `main/` — location-relevant Barcelona / Catalonia imagery to prioritize.
- `extras/` — generic premium residential imagery for supporting sections only.
- `web/` — optimized WebP versions (max 1800 px wide) for implementation.
- `contact-sheet.jpg` — quick visual index.
- `design-agent-prompt.md` — complete build/design brief.

## Important usage rule

These are stock/editorial mood images, **not actual listings represented by Your Home Barcelona**. Never add fabricated addresses, prices, availability, bedrooms, or “for sale” labels. Do not imply a generic image is a property Steve or his partner agency is selling. Images in `extras/` are deliberately named `generic-*`; do not relabel them as Barcelona-specific properties.

## Recommended use

1. `main/04-barcelona-mediterranean-facade.jpg` — strongest homepage / Barcelona residential mood candidate.
2. `main/01-costa-brava-coastal-view.jpg` — Costa Brava coverage section.
3. `main/02-begur-coastal-home.jpg` — Costa Brava / second-home supporting image.
4. `main/06-barcelona-residential-home-greenery.jpg` — metropolitan Barcelona / houses and gardens.
5. `main/07-classic-residential-balconies.jpg` — architectural detail / content divider.
