Features

Documents

Deeds, warranties, manuals and receipts, filed where you can actually find them again.

Maintenance

Seasonal reminders for the jobs that are cheap to do on time and expensive to forget.

Costs

Track spending per room, per project, or per year, and see where the money actually goes.

Inventory

Appliances, serial numbers and warranty dates — ready the moment something breaks.

How it works

  1. Add your home. Address, build year, and the basics.
  2. Fill it in as you go. Drop in a document or a receipt whenever one shows up.
  3. Get reminded. YourHome surfaces what's due before it becomes a problem.

FAQ

Where is this site hosted?

On GitHub Pages, deployed automatically from the site/ directory of this repository.

How do I change the content?

Edit the files under site/ and push to the default branch. The deploy workflow publishes the update.

Can I use a custom domain?

Yes — add a CNAME file containing your domain to site/, then point the DNS record at GitHub Pages.
